## Why this matters

`.claude/commands/qa.md` is the top-level dispatcher command (`/qa`) that every
other command routes through. It documents and routes to a `/qa-ado` command
in two places, but `.claude/commands/qa-ado.md` does not exist — it was
deliberately removed. `CHANGELOG.md` under `## [2.2.0]` states: "Replaced
`qa-ado.md` with the platform-agnostic `qa-refinement.md`." The removal
happened but `qa.md` was never updated to match, so both the compiled
`.claude/commands/qa.md` and every generated adapter (`adapters/cursor/qa.mdc`,
`adapters/windsurf/qa.md`, `adapters/copilot/copilot-instructions.md`,
`adapters/cline/.clinerules`, `adapters/antigravity/qa/SKILL.md`,
`adapters/universal/AGENTS.md`, `adapters/universal/CLAUDE.md`) currently tell
every AI editor to route ADO/work-item-review requests to a command that
doesn't exist. This is a broken, user-visible dispatch table in the package's
primary entry point.

## Steps

### Step 1: Update the "Specialized Active Commands" table

In `.claude/commands/qa.md`, remove the `/qa-ado` row from the table at line
18 (between the `/qa-bdd` row and the `/qa-automate` row). Do not renumber or
otherwise touch the other rows — just delete that one line so the table reads
`/qa-cases` → `/qa-defect` → `/qa-bdd` → `/qa-automate`.

**Verify**: `grep -n "qa-ado" .claude/commands/qa.md` → no output.

### Step 2: Update the "Smart Routing" table

In the same file, at line 44, replace the routing row that points ADO/story
review requests at the now-nonexistent `/qa-ado` command with one that points
at `qa-refinement.md`, consistent with the changelog's stated replacement and
with how the other rows in that table reference skills/agents (e.g. line 48:
`| "code review", "testability", "static analysis" | Invoke **Static
Reviewer Agent** (`agents/qa-engineer.md`) |`).

Replace:

```markdown
| "review story", "review epic", "ADO check"                | Apply `/qa-ado` active command                                      |
```

with:

```markdown
| "review story", "review epic", "ADO check", "refine ticket" | Apply `/qa-refinement` active command                              |
```

**Verify**: `grep -n "qa-refinement" .claude/commands/qa.md` → matches both the
existing bullet under "Declarative Rules & Auto-loaded Skills" section (if
present) and this new routing row. `grep -n "qa-ado" .claude/commands/qa.md`
→ no output.

### Step 3: Regenerate compiled adapters

Run `./generate-adapters.sh --clean` from the repo root. This rebuilds every
file under `adapters/` from the updated `.claude/` sources — do not edit
`adapters/` by hand.

**Verify**: `./generate-adapters.sh --clean` exits 0 and prints `success "All
adapters generated (7 files)"`. Then `grep -rn "qa-ado" adapters/` → no
output.
