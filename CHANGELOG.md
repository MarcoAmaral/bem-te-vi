## [2.0.0] - 2026-05-22

### Changed — BREAKING (Multi-Directory Folder Structure)

**Modern Folder Structure Mapping**: Migrated from a flat command architecture to the formal **Claude Code Multi-Directory Folder Structure** (`rules/`, `commands/`, `skills/`, `agents/`, `hooks/`, `CLAUDE.md`). This guarantees multi-model agnosticism, native IDE auto-loading, and zero-build compatibility.

| Component                 | Target Path         | Purpose                                                                                                                                                |
| ------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Dispatcher & Commands** | `.claude/commands/` | Dispatcher `qa.md` + active commands (`qa-cases.md`, `qa-defect.md`, `qa-bdd.md`, `qa-refinement.md`, `qa-tdd.md`, `qa-automate.md`)                   |
| **Declarative Rules**     | `.claude/rules/`    | Automatically loaded static rules: `testing-guidelines.md` (testing principles & tagging) and `code-style-qa.md` (E2E Page Object Model & Unit styles) |
| **Auto-loaded Skills**    | `.claude/skills/`   | On-demand task-matching skills: `qa-plan/SKILL.md` (test plans & risk registers) and `qa-explore/SKILL.md` (exploratory charters & SBTM)               |
| **Specialized Agent**     | `.claude/agents/`   | Review agent rules: `qa-engineer.md` (review persona for code and testability reviews)                                                                 |
| **Automated Hook**        | `.claude/hooks/`    | Git pre-commit shell hook: `validate-tc-format.sh` (automatic validation of test case frontmatter formats)                                             |
| **Project Entry Point**   | `CLAUDE.md`         | Primary instruction guidelines for setup, compilation, and folder structures                                                                           |

### Added (v2.0.0)

- Smart dispatcher `/qa` (`.claude/commands/qa.md`) routes user intent to specialized rules, commands, skills, or reviewer subagents.
- Multi-editor compilers recursively crawl the multi-directory structure and assemble cohesive single-file editor adapters (`adapters/`).
- Installer script automatically scaffolds the complete structure and registers the pre-commit hook validator both globally and project-locally by default (with a `--no-hooks` / `-NoHooks` bypass flag).
- Automated hook `validate-tc-format.sh` automatically enforces test case standard frontmatter when files matching `TC-*.md` are committed.
- Reference textbooks (`CTFL/` and `EngSW/`) are untracked by Git to protect intellectual property, prevent repository bloat, and stop context window pollution.

### Changed (v2.0.0)

- `install.sh` and `install.ps1` updated to support v2.0 multi-directory scaffolding and local/global Git hooks.
- `generate-adapters.sh` and `generate-adapters.ps1` updated to recursively build unified adapters from `.claude/{rules,commands,skills,agents}`.
- `README.md` and `CHANGELOG.md` updated to reflect the new structure, token savings, and installation options.
