Reported By    : QA Engineer
Date Reported  : 2026-10-14

Severity       : High
Priority       : P2 (High)
Status         : New

Application    : shop 4.12.0-rc.2
Environment    : Staging
OS / Browser   : Ubuntu 22.04 / Chromium 129.0.6668.29

Steps to Reproduce :
  1. Sign in as the EUR test user
  2. Add "Desk Lamp" (EUR 49.00) to the cart and open checkout
  3. Apply gift card GC-TEST-0042 (balance EUR 20.00)

Expected Result :
  The order summary shows "Gift card: -€20.00" and a total of €29.00.

Actual Result :
  The toast "Something went wrong. Please try again." appears and the total stays €49.00.
  POST /api/checkout/gift-card returns 500 with {"error":"TypeError: Cannot read properties of undefined (reading 'currency')"}
