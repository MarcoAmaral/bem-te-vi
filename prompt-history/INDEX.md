## How to Add a New Entry

1. Copy `_TEMPLATE.md` and rename it: `YYYY-MM-DD_HH-MM_slug.md`
2. Fill in all frontmatter fields and sections
3. Add a row to the table above

**Column guide:**

- **Date**: `YYYY-MM-DD`
- **Session File**: link to the file, e.g. `[2026-03-24_login](2026-03-24_14-30_login-user-story-review.md)`
- **Topic**: 1-sentence description
- **Module**: Feature/component/epic name
- **Tags**: comma-separated from the tags reference list
- **Key Artifacts**: what was produced (test cases, Playwright spec, risk matrix, etc.)
